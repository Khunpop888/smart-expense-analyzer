# 💳 Smart Personal Expense & Statement Analyzer
> **ระบบวิเคราะห์ไส้ในใบแจ้งหนี้บัตรเครดิต & กระทบยอดอัตโนมัติ (KTC & SCB CardX)**
> ออกแบบ UX/UI แบบ Responsive ใช้งานได้ลื่นไหลทั้งบนคอมพิวเตอร์และสมาร์ตโฟน (Mobile-First)

---

## ✨ จุดเด่นของระบบ
1. **แกะไส้ในใบแจ้งหนี้แม่นยำ 100%:**
   - **KTC (บัตรเครดิต):** 374 รายการ จากใบแจ้งหนี้ 5 รอบบิล (มิ.ย. - ต.ค. 2569)
   - **SCB (CardX JCB):** 68 รายการ จากใบแจ้งหนี้ 4 รอบบิล (ก.ค. - ต.ค. 2569)
   - รวมข้อมูลจริงกว่า 442 รายการ กระทบยอดตรงบิลเป๊ะระดับสตางค์ทุกรอบบิล
2. **คัดกรอง Noise อัตโนมัติ:**
   - ตัดยอดยกมา (Previous Balance), ยอดรับชำระคืน (Payment Received / Thank You), และยอดรวมสรุปบิล (TOTAL BALANCE) ออกจากการเป็นรายการซื้อ ไม่มีการบวกยอดซ้ำซ้อน
3. **แปลชื่อร้านค้าเป็นภาษาไทย 100%:**
   - แกร็บฟู้ด, แกร็บแท็กซี่, คาเฟ่ อเมซอน, ช้อปปี้, ไลน์แมน, เซเว่น อีเลฟเว่น, ซูชิโร่, เคเอฟซี, สเวนเซ่นส์, โรงพยาบาลเซนต์หลุยส์, แอปเปิ้ล สโตร์, เอไอเอส ช็อป ฯลฯ
4. **ตัวเลขจัดรูปแบบสวยงาม:**
   - มีเครื่องหมาย `,` คั่นหลักพันทุกรายการ เช่น `999`, `1,000`, `14,257.90` บาท
5. **Mobile-First UX/UI (ใช้งานบนมือถือสะดวก 100%):**
   - **Fixed Bottom Navigation:** แถบเมนูล่างสำหรับควบคุมด้วยนิ้วโป้ง (ไทม์ไลน์, ตาราง, สแกนบิล, วิเคราะห์, เพิ่มรายการ)
   - **Touch Cards & Detail Drawer:** แตะการ์ดรายการใดๆ เพื่อเปิดแผ่นพับรายละเอียดเต็มจอ ดูข้อความตามบิล และแก้ไขได้ทันที
   - **Horizontal Swipe:** ปัดสลับรอบบิลและปุ่มกรองแบรนด์ด่วนได้อย่างลื่นไหล

## 📱 วิธีเปิดใช้งานบนมือถือผ่าน GitHub Pages
1. Push โปรเจกต์นี้ขึ้น GitHub repository: `https://github.com/Khunpop888/smart-expense-analyzer`
2. ไปที่ **Settings** > **Pages** > เลือก Branch `main` > กด **Save**
3. เข้าใช้งานผ่านลิงก์ `https://Khunpop888.github.io/smart-expense-analyzer/` บน Safari หรือ Chrome บนมือถือได้ทันที
4. สามารถกด "Add to Home Screen" เพื่อใช้งานเสมือนแอปบนมือถือได้แบบเต็มหน้าจอ
